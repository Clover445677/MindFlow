# MindFlow 🧠

Прототип браузерного трекера привычек на HTML, CSS и JavaScript. В интерфейсе предусмотрены добавление привычек, выбор частоты и типа, отметки выполнения, прогресс, статистика и переключение темы. Для хранения данных используется `localStorage`.

## Текущее состояние

Проект находится в разработке. В текущем [app.js](app.js) есть синтаксические ошибки, которые блокируют выполнение скрипта:

- В `addHabit` повторно объявлены `const name`, `const frequency` и `const habit`.
- В `saveToStorage` попала HTML-разметка вне строкового литерала.
- Часть логики таймера и прогресса вставлена вне предназначенных для неё функций.

В [index.html](index.html) также нужно исправить вложенность элементов формы и повторяющиеся закрывающие теги. Расчёт процента выполнения пока возвращает фиксированное значение `50`, а статистика требует реализации.

## Как открыть

Скачайте репозиторий и откройте `index.html` в браузере для просмотра интерфейса. Полноценная работа трекера станет возможной после исправления перечисленных ошибок.

Для просмотра через локальный сервер, если установлен Python 3:

```bash
git clone https://github.com/Clover445677/MindFlow.git
cd MindFlow
python -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Сборка и установка npm-зависимостей не требуются.

## Хранение и оформление

Привычки сохраняются в `localStorage` под ключом `mindflow_habits`, тема — под ключом `theme`. Данные относятся к конкретному браузеру и адресу страницы; синхронизации между устройствами нет.

Для шрифтов и значков подключены Google Fonts и Font Awesome через CDN.

## Проверка JavaScript

При установленном Node.js синтаксис можно проверить без запуска приложения:

```bash
node --check app.js
```

В текущей версии эта проверка завершается ошибкой повторного объявления `name`.
