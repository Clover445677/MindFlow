# MindFlow 🧠

## Описание

MindFlow — это простой трекер привычек с поддержкой светлой и тёмной темы, прогресс-баров и статистики выполнения. Приложение использует localStorage для хранения данных и работает полностью в браузере.

## Как запустить

1. Откройте файл `index.html` в браузере
2. Начните добавлять привычки и отслеживать их выполнение

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, анимации)
- JavaScript (ES6+)
- localStorage
